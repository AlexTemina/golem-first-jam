# GDD — *Chicken Flee* (título provisional)

Game Design Document de la entrada de Golem para la game jam. Está partido en
archivos cortos para que se pueda leer a trozos.

Hay también una versión **visual y navegable** de todo esto (ver
`docs/gdd/gdd.html`), pensada para leerla de una sentada o para enseñarla.

| [02-controles.md](02-controles.md) | Mapeo de botones actual y el problema de reparto |

## Convención

- Lo marcado **[DECIDIDO]** viene de diseño y está cerrado.
- Lo marcado **[ABIERTO]** está sin decidir; no lo rellenéis a la ligera, está
  recogido en [12-preguntas-abiertas.md](12-preguntas-abiertas.md).
- Lo marcado **[CÓDIGO]** describe lo que ya hace el proyecto hoy, con el
  archivo donde mirarlo.
